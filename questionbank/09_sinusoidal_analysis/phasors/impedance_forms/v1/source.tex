\textbf{Useful relationships:}

To convert in general, starting with a Cartesian form of impedance
\[
Z = a + jb,
\]
the polar form is
\[
|Z| \angle \tan^{-1}\!\left(\frac{b}{a}\right),
\]
and Euler’s form is
\[
|Z| e^{j\tan^{-1}(b/a)},
\quad \text{where } |Z| = \sqrt{a^2 + b^2}.
\]

\medskip

The \emph{series equivalent circuit} consists of a resistor of value $a$ and:
\begin{itemize}
\item an inductor of value $b$ if $b > 0$,
\item a capacitor of value $\dfrac{1}{|b|}$ if $b < 0$.
\end{itemize}

\medskip

The \emph{parallel equivalent circuit} consists of a resistor of value
\[
\frac{a^2 + b^2}{a}
\]
and:
\begin{itemize}
\item an inductor of value $\dfrac{a^2 + b^2}{b}$ if $b > 0$,
\item a capacitor of value $\dfrac{b}{a^2 + b^2}$ if $b < 0$.
\end{itemize}

\medskip

The admittance is
\[
Y = \frac{1}{Z}
= \frac{a - jb}{a^2 + b^2}
= \frac{a}{a^2 + b^2}
- j\frac{b}{a^2 + b^2}.
\]

From this:
\[
G = \frac{a}{a^2 + b^2}, \qquad
B = -\frac{b}{a^2 + b^2}.
\]

\medskip

Starting with any of the first six columns, you can determine the remaining
entries using the relationships above.
